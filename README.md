# SIT305 Task 5.1C – Media and Content Apps

## Overview
This project contains two apps: Sports News App and iStream App

## What can the Sports News app do?
- Featured Matches
- Latest Sports News
- Search by category
- Bookmarks screen
- Related stories section

 ## Technologies Used
- Java
- Android Studio

## How does it work?
The app let the user search sports news by category and add bookmarks

## How to run the app
Open the project in Android Studio and run it on an emulator or phone.

## What can the iStream app do?
- User authentication (Signup & Login)
- Room Database for storing users and playlists
- YouTube URL input and playback (WebView)
- Add videos to personal playlist
- View playlist
- Logout functionality

## Technologies Used
- Java
- Android Studio
- RecyclerView
- Fragments
- Room Database
- WebView
